# 麦麦的绘图笔记本（mai-prompt-journal）

- 2.4.0 版本起已经支持笔记本的导入和导出，方便为他人分享你自己的笔记本。我们推荐导出为 **mpj** ，它包含笔记本内容和索引，若其他人和你使用相同的 embedding 模型，那么他们可以复用你的索引，无需完整重建笔记本索引。支持配置自己的 embedding OpenAI 接口地址，你可以为一份笔记本使用不同 embedding 模型导出多份 mpj 文件，以满足使用不同 embedding 模型的其他人。
- 如果你想快速了解怎么用，请往下翻到**快速上手**段落。
- 事先声明，由于本插件也有一个独立于麦麦自身界面的 WebUI ，后续将用**麦麦的/自带的 WebUI**区分其和本插件提供的专属 WebUI 界面。

这个插件本质上相当于一个外置的，脱离 A-Memorix 的专门针对 Stable Diffusion 等本地 AI 绘画提示词优化的专属记忆系统。

起初为个人自用（一方面实在是有点史山，另一方面很多人可能会给麦麦配置GPT或者香蕉绘图而不是24H开电脑挂本地模型导致受众可能不多），经过几天的修修补补之后，想了想决定上传一份到仓库，万一有人觉得有用呢（）

插件大幅使用 Vibe Coding 优化（单文件史山终于消失了），并保留完整AGENTS.md，你可以随时丢给你的 AI 帮你解答使用方法问题和开发新功能。



这是一个给麦麦用的"绘图提示词笔记本"，它自身不提供 AI 绘画功能，但可以让你家麦麦记录TA学到的绘画经验，不断积累。插件还支持网页内管理，用 LLM 整理你的数据库，在网页内直接输入成品提示词组合让麦麦积累经验。

麦麦自己或管理员可以把绘图标签经验（英文 tag + 中文释义 + 备注）写进多本"笔记本"，之后通过**语义检索**随时回忆历史经验，避免重复踩坑。

- 支持多笔记本（自带 `default`，可在 `imports/` 投放第三方笔记本），你可以把自己记录的笔记本重命名后分发给别人，让他们导入给自己的麦麦
- 向量检索 + 文本加分重排，中文 / 英文都能搜
- 自带 WebUI，支持搜索、去重、整库整理、索引管理
- LLM 相关功能通过插件直连 OpenAI 兼容 API，不使用麦麦自带的模型配置

## 功能特性

| 功能 | 说明 |
|------|------|
| AI 工具 | `add / read / modify / delete_aidraw_notes` 工具，AI 可自主记录和检索经验 |
| SubAgent 提示词生成 |  `aidraw_prompt_generate` 工具，由子代理检索笔记本生成成品提示词，更省上下文（需配置 LLM 直连） |
| 管理员命令 | `/mpj add/search/modify/delete/refresh/rebuild/help` |
| 语义搜索 | 相似度阈值过滤 + 关键词加分重排，支持跨笔记本搜索 |
| 自带 WebUI 去重 | 扫描语义重复组，支持"LLM 整理"（AI 把重复项整理成 1~N 条干净条目），并可单独修改/删除组内条目 |
| LLM 操作数据库 | 让 LLM 审查整本笔记本并给出 create / update / delete 方案，可多轮追加要求、确认后写入 |
| txt 批量写入 | 上传 txt 自动切分，逐段 LLM 处理（可选引用笔记本避免重复），临时笔记本 + 完整日志，完成后可合并/新建/丢弃 |
| 笔记本管理 | WebUI 列出所有笔记本，可新建空白笔记本、一键删除已有笔记本（default 与临时笔记本除外） |
| 索引管理 | 增量重建（支持 `--full` 全量重建），手动改源文件后自动检测失效并提示重建 |

## 安装

1. 在插件商店点击安装，等几分钟就行。
- 注：如果插件商店安装出现问题需要手动安装，把本插件目录放入麦麦的 `plugins/` 目录（例如 `data/MaiMBot/plugins/mai-prompt-journal`）。
2. 在麦麦的插件管理页启用插件，或重启麦麦。

依赖：`numpy`、`aiohttp`（插件加载时自动安装）。

## 快速上手！

- 若想要快速品尝到此插件的完全体，请在安装好插件之后，配置如下项目：

1. 打开 **启用SubAgent构建提示词** 。

2. 把你的账号写入 **管理员 QQ 号**里。

3. 打开 **启用 WebUI** 并完成基础配置（考虑到安全问题，该项目没有被默认打开）。

4. 配置 **LLM 直连** 并配置你的 API 信息（可使用麦麦 planner 相同的模型提供商 API 地址）。

5. 修改 **行为风格**（麦麦设置内，不在本插件配置页面） ，要求其绘图前搜索并使用工具 `aidraw_prompt_generate` 构建提示词。

## 配置说明（config.toml）

> 所有配置改动都需**重启 / 重载插件**才生效。配置在麦麦内的本插件对应插件配置页修改。

| 配置节 | 说明 |
|--------|------|
| `[plugin]` | 插件开关与配置版本 |
| `[journal]` | 搜索默认返回条数、最低相似度阈值（默认 0.4）、批量 embedding 并发数、允许 LLM 写入（只读开关）、写入去重检测（开关、是否跨笔记本、阈值默认 0.85）、SubAgent 构建提示词开关、子代理最大检索轮数 |
| `[admin]` | 能执行 `/mpj` 命令的 QQ 号列表 |
| `[web]` | 是否启用插件自带 WebUI、端口（默认 8010）、访问密码、监听地址（默认 127.0.0.1） |
| `[llm]` | LLM 直连配置，见下 |
| `[dedup_merge]` | 去重"LLM 整理"的开关（系统提示词在 `[advanced]`） |
| `[organize_db]` | "LLM 操作数据库"的开关、最大检索轮数、单次检索条数（系统提示词在 `[advanced]`） |
| `[advanced]` | **高级**：去重整理系统提示词、操作数据库系统提示词、txt 批量写入追加提示词、SubAgent 提示词生成系统提示词、去重扫描分块大小（默认 256）——默认不建议修改 |
| `[backup]` | 自动备份：开关（默认开）、每个笔记本的备份上限（默认 6，超出自动删最旧） |

### LLM 直连（在插件自带的 WebUI 使用 LLM 管理数据库相关功能时必填）

去重整理和整库操作都需要调用 LLM，由于调用麦麦自带的LLM服务不是很灵活，插件设计为**直连** OpenAI 兼容 API，不走麦麦自带模型：

```toml
[llm]
base_url = "https://api.example.com/v1"   # OpenAI 兼容地址（必填）
api_key = "sk-xxxx"                        # API 密钥（必填）
model = "deepseek-v4-flash"                # 具体模型名（必填）
temperature = 0.2                          # 生成温度
max_tokens = 10000                         # 最大输出 token
timeout = 120                              # 单次请求超时（秒）
extra_params = ""                          # 额外透传参数，如 {"enable_thinking": false}
```

- `base_url` / `api_key` / `model` 任一为空时，相关功能会直接报"LLM 直连配置不完整"，拒绝执行。
- 搜索用的 embedding 仍由麦麦提供（保证与已存笔记向量一致），无需单独配置。

## 使用方式

### 1. 给 AI 用的工具

AI 在对话中会自动使用这些工具，管理员无需手动调用：

- `add_aidraw_notes`：写入一条或多条笔记（en / zh 必填，note 可填经验与使用场景）。批量写入时会做**去重检测**：与已有笔记重复度过高的条目会被拒绝写入，并在返回值中告知匹配到的重复笔记（可配置开关/是否跨笔记本/阈值）
- `read_aidraw_notes`：按关键词语义搜索相关经验
- `modify_aidraw_note`：按笔记 ID 修改某条（可只改部分字段）。若新内容与已有笔记重复度过高，修改会被拒绝并附匹配笔记
- `delete_aidraw_note`：按笔记 ID 删除某条
- `aidraw_prompt_generate`：传入绘图要求，由子代理检索笔记本后生成一段成品英文提示词 + 中文说明（更省上下文，需在配置页开启「启用SubAgent构建提示词」并在 [llm] 配置直连）

### 2. 管理员命令

发送给麦麦（需 QQ 号在 `[admin]` 列表中）：

```
/mpj add 英文|中文[|备注] [-n 笔记本]      # 添加笔记
/mpj search 关键词 [-n 笔记本或all]        # 语义搜索
/mpj modify ID 字段=值 [...] [-n 笔记本]   # 修改笔记（字段可选 en/zh/note）
/mpj delete ID [-n 笔记本]                 # 删除笔记
/mpj refresh                               # 重载笔记本并查看状态
/mpj rebuild                               # 增量重建所有笔记本的向量索引
/mpj rebuild --full                        # 全量重建所有索引（换 embedding 模型后使用）
/mpj new 笔记本名                           # 创建空白笔记本
/mpj confirm 确认码                         # 确认写入被去重检测拦截的 add/modify 操作
/mpj backup list [-n 笔记本]                # 查看笔记本备份
/mpj backup restore 时间戳 [-n 笔记本]       # 恢复备份（恢复前自动备份当前状态）
/mpj backup delete 时间戳 [-n 笔记本]        # 删除备份
/mpj help                                  # 查看帮助
```

> 说明：`/mpj add` / `/mpj modify` 检测到与已有笔记重复度过高时**不会直接写入**，而是返回匹配到的重复笔记并附一个确认码，发送 `/mpj confirm <确认码>` 才会写入（确认码 10 分钟内有效）。可在配置里关闭该检测。

非管理员用户的消息会被静默忽略。

### 3. 插件自身的 WebUI

这是插件自带的专用 WebUI 界面，负责一些聊天软件内难以交互的高级功能，和麦麦自己的 WebUI 不是一个东西，需要区分。

使用前先打开麦麦的本插件配置页内的 WebUI 选项。

浏览器打开 `http://<麦麦地址>:8010`（Docker 部署需在容器端口映射中放行，并输入 `[web] password`）。

> ⚠️ **安全说明**：`[web] bind` 默认是 `127.0.0.1`（仅本机可访问）。如果改为 `0.0.0.0`（局域网/公网暴露），**必须同时设置 `[web] password`**——否则插件会进入安全警告模式：所有请求都只返回一个警告页（提示你去插件配置界面设置密码或改回 127.0.0.1），无法读取或修改任何数据。WebUI 登录使用 **HttpOnly cookie**（浏览器自动携带，JS 无法读取），密码不会存进 `localStorage` 或 URL。

- **搜索**：语义搜索，结果可直接内联编辑（改 en/zh/note 后保存）
- **去重**：扫描重复组 → 每组条目可单独修改/删除，或用"LLM 整理"（AI 重排成 1~N 条并给理由）→ 预览后确认执行；每次处理完自动重建索引
- **操作数据库**：选"写入笔记"或"整理笔记"，输入要求 → AI 检索整库并生成 create/update/delete 方案 → 可继续**追加要求**让 AI 覆盖重出 → 满意后确认执行。任务进行中会显示检索进度
- **txt 批量写入**：上传一份 txt → 自动按段落切分预览 → 选择模式（学习描述方式 / 导入oc设计 / 提取动作模板 / 提取服饰穿搭 / 自定义附加提示词）和引用笔记本（可多选/不选）→ 逐段交给 LLM 处理写入**临时笔记本**（可下载完整日志，失败段自动跳过）→ 完成后可查看/编辑临时条目，并可**合并入已有笔记本**、**新建笔记本**或**丢弃**
- **笔记本管理**（选项卡一）：列出所有笔记本，可新建空白笔记本、删除不需要的笔记本（default 与临时笔记本除外），并内置**备份**区（每次修改后自动按时间戳备份，上限默认 6，可查看 / 恢复 / 删除，恢复前自动备份当前状态）
- **导入 / 导出**（选项卡二）：下载支持 jsonl （仅笔记本内容）与 mpj（笔记本内容以及一份索引）；mpj 可"直接导出"或"用第三方 embedding 重新生成索引导出"（第三方配置可保存复用，含 embedding 并发数），导出均为后台任务，完成后在状态区提供下载按钮。上传支持 jsonl 与 mpj（点击 / 拖拽选择文件）：jsonl 不包含索引，导入时必须为其计算索引；mpj 包含一份索引，导入前先校验（校验码是否一致 / 向量维度 / 抽样相似度平均与最小值，抽样条数填 0 表示不校验相似度），确认后可**直接导入**或**重建索引导入**，目标可**新建笔记本**（默认取上传文件名）或**合并到已有**（合并后建议去重）。若 mpj 的校验码缺失或不一致，会提示"可能被第三方修改，极其不建议导入"并要求确认后继续。导入/导出共用一套**抗刷新状态机**，页面刷新不丢进度，进行中可**取消**并显示 `(已完成/总数)` 进度
- **索引**：全局导航栏右侧的 刷新 / 重建索引 / 全量重构索引 按钮（所有页面可见）

## 数据存储

数据目录：`data/plugins/mai.prompt-journal/`。每本笔记本由 4 个文件组成（`{name}` 为笔记本名）：

| 文件 | 说明 |
|------|------|
| `{name}.jsonl` | 笔记源文件（人类可直接编辑） |
| `{name}.cache.jsonl` | 与向量索引对齐的内部快照 |
| `{name}.embeddings.npy` | 向量矩阵（float16） |
| `{name}.index.meta` | 索引元信息（md5、条数、构建时间） |

- `default` 笔记本在数据目录根目录；第三方笔记本放 `imports/{name}.jsonl`，执行 `/mpj refresh` 后被发现
- **txt 批量写入临时笔记本**：`tmp_import/` 目录下的 `tmp.*` 文件，固定名 `tmp`，导入完成后保留（可查看/编辑），下一轮导入开始前自动清空
- **手动编辑 jsonl 会触发 MD5 校验失效**，此时写操作会提示先 `/mpj rebuild`

## 常见问题

**提示"索引失效，请执行 /mpj rebuild"**
源文件被手动改动过，向量索引与内容不一致。执行 `/mpj rebuild`（或自带的 WebUI 内重建索引）即可，未变内容会复用旧向量。

**换过 Embedding 模型后搜索不准 / 想强制重算全部向量**
给麦麦发送 `/mpj rebuild --full`，或在自带的 WebUI 点击**全量重构索引**。

**LLM 功能报"LLM 直连配置不完整"**
`config.toml` 的 `[llm]` 未填 `base_url` / `api_key` / `model`。LLM 直连始终启用，补齐这三项后重启插件即可。

**操作数据库 / txt 批量写入执行失败或一直检索不出结果**
可能与配置中的**最大检索轮数**（`[organize_db] max_iterations`）有关（默认 8）。它限制了 LLM 调用 `search_notes` 的最大轮次，达到上限会提示"LLM 检索达到最大迭代次数"而失败。若检索要求较复杂，可在插件配置页调大该值后重试；txt 批量写入共用此限制。

**自带的 WebUI 打不开**
确认 `[web] enabled = true`、端口映射已放行（Docker 需在 compose 中加 `-p 8010:8010`）。

**打开 WebUI 却只看到"未安全配置"警告页**
`[web] bind` 绑定了非 `127.0.0.1` 的地址但没有设置 `password`。请到插件配置界面设置 `[web] password`（或将 `bind` 改回 `127.0.0.1`），然后重启 / 重载插件。
