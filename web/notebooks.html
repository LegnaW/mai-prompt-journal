可新建空白笔记本，或删除已有笔记本。删除后该笔记本的笔记数据将不可恢复；default 与临时笔记本不可删除。
备份
每次笔记本被修改后自动按时间戳备份（上限可在插件配置『备份』分类调整）。恢复前会自动先备份当前状态，便于撤销。
导入
上传 jsonl 或 mpj 文件；mpj 会校验完整性（校验码 / 向量维度 / 抽样相似度），可新建或合并到已有笔记本。
点击选择 或 拖拽 jsonl / mpj 文件到此处
支持 .jsonl 与 .mpj
填 0 表示不校验相似度
导出
支持 jsonl 与 mpj（含索引 + 校验码）；mpj 可"直接导出"或"用第三方 embedding 重新生成索引导出"。导出完成后在下方状态区下载。
第三方 embedding 配置（用于重新生成索引导出；保存到服务器，下次自动预填）
