# 操作数据库使用说明

通过 LLM 审查整本笔记本，生成 create / update / delete 操作方案，确认后统一写入。

## 一、选择笔记本与模式

1. 在「笔记本」下拉框选择要操作的笔记本。
2. 选择「模式」，决定附加提示词：

| 模式 | 说明 |
|------|------|
| 学习描述方式 | 从你提供的文本中提取有学习价值的 tag 组合 / 搭配 |
| 导入人物形象 | 将角色名称与形象设定整理为笔记 |
| 提取动作模板 | 去掉形象描述，仅保留动作部分 |
| 无附加提示词 | 不附加任何提示词，直接按你的要求操作 |

3. 选择「无附加提示词」时，直接在「操作要求」框填写你的操作要求；其他模式可填写补充说明。

## 二、生成操作方案

1. 点击「生成操作方案」，LLM 会先检索笔记本内容（页面会显示"正在检索：xxx"进度）。
2. 完成后展示操作方案：
   - **新建**：新增笔记条目。
   - **修改**：修改已有条目，显示 旧值 → 新值。
   - **删除**：删除已有条目。
3. 若对方案不满意，可在「补充要求」框输入追加要求并点击「追加要求」，AI 会重新生成完整方案覆盖上一轮。

## 三、确认执行

1. 确认方案无误后，点击「确认执行」。
2. 系统会按方案写入并重建索引。
3. 执行成功后本次会话结束；可再次发起新的操作。

## 四、注意事项

- 每次点击「生成操作方案」都会新建一个会话，追加要求在同一会话内覆盖式重出。
- 若方案为空（无需修改），会提示"方案为空：无需执行"。
- 操作前请确保笔记本索引有效；若提示索引失效，请先重建索引。
