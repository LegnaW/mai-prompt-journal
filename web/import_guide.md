# txt 批量导入使用说明

通过本功能，可以把一份 txt 提示词文本批量交给 LLM 处理，自动整理成绘图笔记本中的笔记条目。整个导入过程分以下几个步骤。

## 一、准备文本

1. 准备一份 `.txt` 文件。
2. 文件会按 **两个及以上连续换行** 自动切分成多段，每一段视为一次独立操作要求。
   - 段落之间用空行（连续两个及以上换行）分隔，多空行也只切一次。
   - 单个换行不会切分。
   - 一整份没有空行的 txt 也会作为一段处理。

### 格式正确的示例

银发少女坐在窗边，发梢微微卷起，身着深蓝水手服，白色领巾随风轻扬。

（中间空行）

masterpiece, best quality, 1boy, black hair, laughing, sweat, playing basketball

（中间空行）

少女双手握着书本，书页在风中轻轻翻动，她抬起右手将散落的头发发别到耳后。

- 以上文件包含 **3 段**（每段之间留一个空行，即两个换行）：会被分成 3 次请求，分别被 LLM 学习记入。

### 反例一：段与段之间只有一个换行

- 例如下面这样：

银发少女坐在窗边，发梢微微卷起。

masterpiece, best quality, 1boy, black hair
- 两段之间只有一个换行（没有空行），会被视为**同一段**，无法分别处理。

### 反例二：用空行以外的方式分隔

- 例如下面这样：

银发少女坐在窗边

----------

masterpiece, best quality, 1boy, black hair

- 用 `----------` 这类分隔线而不是空行，不会被识别为分段符，整份内容仍是一个段落（分隔线本身也会被当作内容交给 LLM）。

## 二、解析预览

1. 在「txt 批量导入」区域，**点击选择** 或 **拖拽** 你的 txt 文件到虚线框内。
2. 选择文件后会自动解析并进入「拆分预览」，显示共切分成了几段。
3. 点击「展开」可查看每一段的具体内容，确认切分是否符合预期。

## 三、配置导入

在「导入配置」区域完成以下设置：

### 1. 选择模式（附加提示词）

| 模式 | 说明 |
|------|------|
| 学习描述方式 | 提取有学习价值的 tag 组合 / 搭配，存入笔记 |
| 导入oc设计 | 将角色名称与形象设定整理为 1 条笔记 |
| 提取动作模板 | 去掉形象描述，仅保留动作部分整理为笔记 |
| 提取服饰穿搭 | 提取提示词中每个人物的服饰穿搭（服装/饰品/附加物品） |
| 自定义 | 自己输入附加提示词，作用于所有段落 |

- 选择预设模式时，附加提示词输入框会自动锁定为对应预设（置灰不可编辑）。
- 选择「自定义」时，需在附加提示词输入框中填写你自己的要求。

### 2. 选择引用笔记本

- 可**多选**，也可**一个都不选**。
- LLM 处理每一段时，检索范围 = 你选中的引用笔记本 + 当前临时笔记本。
- 引用已有的笔记本可帮助 LLM 判断是否与历史内容重复，避免产生重复条目。

### 3. 开始导入

点击「开始导入」后进入构建状态，页面顶部「当前活跃任务」栏与「导入状况」面板会同步显示进度。

## 四、导入中

- 每一段会独立交给 LLM 处理，LLM 可以多次检索后输出 create / update / delete 操作。
- 所有操作**只写入临时笔记本**，不会改动你已有的笔记本。
- 若某一段处理失败（LLM 超时 / 输出无法解析等），该段会被跳过，并记录到错误列表，其余段落继续处理。
- 如需中止，可在「导入状况」面板点击「取消导入」，会中断任务并清空缓存。

## 五、构建完毕，等待导入

处理完成后进入「等待导入」状态，你可以：

1. **浏览临时笔记本**：展开后可查看 LLM 整理出的全部条目，每条可单独 **编辑** 或 **删除**。
2. **查看错误列表**：处理失败的段落会以红色列出（默认收起）。
3. **下载日志**：可下载完整日志，查看每段的时间、输入、LLM 决定与失败原因。

## 六、处置临时笔记本

检查满意后，选择一种处置方式：

| 方式 | 说明 |
|------|------|
| 合并入已有笔记本 | 将临时笔记追加进某个已有的笔记本 |
| 新建笔记本 | 以临时笔记为内容，新建一本笔记本（可重命名） |
| 删除 | 丢弃本次导入的结果，清空缓存 |

完成后即进入「已完成」状态，可重新上传 txt 开始新一轮导入。
