# 语义去重使用说明

对笔记本内语义相似的笔记进行扫描，发现重复组，再通过 LLM 整理或手动编辑清理。

## 一、选择笔记本与阈值

1. 在「笔记本」下拉框选择要扫描的笔记本。
2. 通过「阈值」滑块调整判定标准（0.5 ~ 0.99）：
   - 数值越高，只有越相似的笔记才会被判为重复。
   - 数值越低，越多"看起来差不多"的笔记会被归入一组。
   - 一般保持在 0.85 附近即可。

3. 点击「扫描」，系统会按语义相似度找出重复组并列出。

## 二、处理重复组

扫描结果中，每一组代表一组疑似重复的笔记。你可以用以下两种方式处理：

### 方式一：直接编辑 / 删除

- 对组内某条笔记，可直接点击右侧「编辑」修改其内容，或「删除」该条。
- 保存 / 删除后会自动重新扫描并刷新列表。

### 方式二：LLM 整理

- 如果想让 AI 把整组合并整理，点击「LLM 整理」。
- 可先在「整理意见」框填写你的整理要求（可选，留空用默认）。
- AI 会把整组内容重写为 1~N 条更精简的笔记，并给出整理理由。
- 预览满意后点击「确认整理」，整组原条目会被替换为整理结果。

## 三、注意事项

- 处理完成后系统会自动重建索引，保证检索结果一致。
- 每次处理完会重新扫描，剩余重复组会即时刷新显示。
- 若提示"索引失效"，请先在首页执行「重建索引」。
